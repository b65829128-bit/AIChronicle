## 实施契约

- 顶层事项注册为决斗，双方胜负分支各有双向财物和行动。普通交易仍立即成交；延后事项接受后只进入待开始，开始按钮由当前会晤的本地操作触发。
- 双方同意同一版本后显示最终条件和两种胜负预估。修改清除接受；关闭未开始会晤撤销约定；已经开始的决斗由独立服务持有冻结副本，会晤销毁不抹掉结果。
- 不按阵营、关系或是否交战隐藏挑战。实际场景、存活成年、健康与可安全进入战斗的条件决定能否开战。不能在另一场实际战斗中叠开新 Mission。
- 保留原版难度和战死配置，通过原版存活模型决定受伤/致命，再调用原版战死流程。不得携带竞技场强制击昏组件；只处理两名实际决斗者，坐骑移除不判胜负，同帧双方倒下按无胜者处理。
- 财物在实战初始化完成、交战开始前保管，战后按实际胜者分支交付并退回未使用部分。开战失败/异常中断返还；真实胜负已确定时，死亡或状态变化导致的行动失败仍按胜负交割财物、列明未履行行动，不虚构回滚战斗或代替继承人作政治承诺。
- 结果以决斗 ID 保证一次结算；主线程、战役 epoch、原遭遇和对象身份必须校验。切档旧请求不再改游戏状态。记录战斗结果与条款履约分别成功或失败。
- `DuelEncounter` 在关闭原版地图对话前设置离开标记，再在原场景退出后完成本次会面收尾；避免原版 `encounter_meeting` 创建整队战斗。战后显示结果并返回地图/原城镇流程，默认不恢复部队交战菜单；城镇、替换后的遭遇、旧战役不清理。结束会面不等于外交停战，签订的放行保护仍单独履行。

## 输入与冻结时机

在实际开战前冻结双方快照：家族 ID、当时声望、当时身份、实际参战武器对应技能、机动技能、实际护甲、影响力领取资格，以及本家族在此前七日内战胜对方家族的次数。

同时计算双方各自获胜的预估。战后从冻结快照中选择实际胜者对应的结果；结算时不读取已经变化的声望、继承身份、阵营或装备重新定价。

`can_gain_influence` 按原版王国身份资格确定。独立家族照常获得声望，实际王国内影响力为 0；基础政治奖励可以显示在调试明细中，不创建可兑换的隐藏余额。是否允许独立家族积累影响力属于另行选择的功能行为。

模型中的实力评分只是奖励估值，不声称精确预测战斗胜率。护甲取实际出场装备四个部位的护甲均值，不计背包和未出场装备；武器技能取当前规则下可用武器中的最高对应技能。徒步用跑动、骑马用骑术。临时血量、赌注金额、携带部队人数、杀死还是击昏均不增加奖励。

## 公式

记 `Rw` 为胜者家族声望，`Rl` 为败者家族声望。`clamp(x,a,b)` 表示将 x 限制在 a 到 b。

### 1. 对手名望与相对名望

```text
L = log2(1 + Rl / 50)
F = clamp(((Rl + 50) / (Rw + 50))^0.12, 0.6, 1.8)
```

50 取原版一级家族门槛，作为名望刻度，也让零声望有定义。对方的“声望 + 50”每翻倍，基础声望奖励增加 5，基础影响力奖励增加 4。对数使后期名望增长仍有收益，但不会按数千声望等比例膨胀。相对名望另外体现无名者战胜著名者的扬名效果，并限制极端比例。

### 2. 双方个人实力

```text
S = (50 + 有效武器技能 + 0.5 × 机动技能) × (1 + 护甲均值 / 100)
D = clamp((Sl / Sw)^0.35, 0.75, 1.4)
```

个人实力相同时 D=1。强敌提高奖励，弱敌降低奖励。幂次和区间限制让名望仍然是主项，避免临时更换低配装备将奖励无限放大。

### 3. 对手身份

| 败者当时身份 | 声望系数 Pr | 影响力系数 Pi |
|---|---:|---:|
| 普通家族成员 | 1.00 | 1.00 |
| 家族领袖 | 1.35 | 1.50 |
| 王国统治者 | 1.70 | 2.00 |

只取最高身份，不叠加。击败权位更高者的政治影响更大，因此影响力的身份系数高于声望。

### 4. 首次正常胜利的基础奖励

```text
声望基础值   = (12 + 5 × L) × F × D × Pr
影响力基础值 = (10 + 4 × L) × sqrt(F × D) × Pi
```

两种奖励分别计算。影响力同样受名望与个人难度影响，但敏感程度较低，更侧重对手身份。基础 12/10 与成长系数 5/4 是本版平衡参数，已用下列场景校准，不是原版现成的决斗常数。

## 重复挑战与最终发放

按“获胜家族 → 败者家族”这一方向统计：开战时刻之前七个游戏日内，零次正常获胜为 100%，一次为 25%，两次及以上为 0%。具体窗口为 `0 <= 开战时间 - 历史时间 < 7 日`，排除当前决斗 ID；开战时冻结计数。

同一对手家族换一个成员、换领袖或换国不重置次数。反过来战胜此前击败自己的家族，可以获得本方向的首次胜利奖励。家族内部切磋不给声望和影响力。认输和异常中断不产生本模型的战斗奖励，约定条款另按实际结果处理，也不计入“正常获胜”历史。

不设压低重大胜利收益的每日统一上限；单场奖励受对数名望、有界差距系数和重复衰减控制。正常击昏与战死使用相同奖励，不额外鼓励死亡。

```text
最终声望   = 四舍五入(声望基础值 × 重复系数 × 已冻结的声望加成)
最终影响力 = 资格成立时，四舍五入(影响力基础值 × 重复系数 × 已冻结的影响力加成)
             资格不成立时为 0
```

只在最后取整，正数 0.5 向上取整。衰减后不再补最低奖励。样例的两种加成都为 1；首版应用现有 MCM“ 双倍声望”开关并冻结倍率，不额外套入整队战斗模型的声望/影响力特长或政策加成，以免同一胜利重复增长。到账通过原版 GainRenownAction / ChangeClanInfluenceAction，记录实际增量。

## 固定样例

家族声望取对应等级的最低门槛，双方个人实力相同、首次正常获胜、无额外加成。下表的影响力是“具备王国身份资格时”的金额；零级独立家族实际影响力为 0。

| 获胜情况 | 声望 | 具备资格时的影响力 |
|---|---:|---:|
| 0 级家族击败 5 级家族普通成员 | 64 | 41 |
| 0 级家族击败 5 级家族领袖 | 86 | 61 |
| 5 级家族击败 5 级家族领袖 | 54 | 49 |
| 5 级家族击败 0 级家族领袖 | 10 | 12 |
| 3 级家族击败 3 级家族领袖 | 36 | 33 |
| 0 级家族击败 6 级家族的国王 | 142 | 101 |

零级家族击败五级家族领袖的具体展开：

```text
Rw=0, Rl=2350, L=log2(48)≈5.584963
F=48^0.12≈1.591289, D=1, Pr=1.35, Pi=1.5
声望≈(12+5×5.584963)×1.591289×1.35≈85.77 → 86
影响力≈(10+4×5.584963)×sqrt(1.591289)×1.5≈61.19 → 61
```

同一组冻结输入下，第二次获胜为 21 声望、15 影响力，第三次为 0。实际重复挑战时使用当时的新快照，因此自己的名望增长后，第二场还会受到相对名望变化影响。

对手个人实力明显更强的固定样例：胜者武器 75、机动 50、护甲均值 10；败者武器 250、机动 175、护甲均值 55。D 达到 1.4，上述零级对五级族长的奖励为 120 声望、72 影响力。

成长轨迹检查：从零声望开始，连续战胜不同的五级家族领袖，双方个人实力相同且每次均无重复衰减，前五场累计为 86、162、234、304、372。第五场达到三级门槛 350；每次新增奖励依次为 86、76、72、70、68，不会始终按最初的越级收益发放。

检查包括 JSON 快照往返一致、无输入修改、对手名望/个人实力单调性、胜者名望/个人实力反向单调性、系数边界、身份区分、重复衰减、无王国资格、同家族、异常中断以及等级门槛附近的连续变化。随机数只用于生成固定种子的测试输入，实际计算不调用随机数。

结果记录决斗 ID、算法版本、双方冻结快照、既往获胜计数、所有系数、资格、加成和最终实际发放值；结算器以决斗 ID 保证只发放一次。日记写可读结果，详细复算字段写结果记录。复算命令只读取记录中的快照，不查询当天的新状态，也不加载游戏 DLL。

数学属性检查用于发现奖励方向、边界和复算错误；实机中的获得感与节奏仍需结合实际决斗频率验证。调整平衡参数时升级版本，并保留旧版本定义，以便复核旧记录。
