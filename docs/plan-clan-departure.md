# 家族成员投族与自立

状态：2026-11-05 按用户确认的简化方案实现并部署，离线回归通过，尚待实机和存档重载验证。只校验客观资格和实际结果，主观意愿由 Agent 根据现有人格、记忆和关系决定；不增加忠诚阈值、付费门槛、原族长审批、远程回信等待或固定关系惩罚。

## 交互契约

- 会晤新增 `join_clan`（加入家族）和 `found_clan`（自立家族）。玩家和 AI 使用现有提案/还价/同版接受；双方财物可以全空。只允许当前会晤的双方本人离族，不能替不在场的成年成员决定。
- `familyId` 选项固定本人、存活配偶、同族未成年子女以及原家族/部队。婚姻、成年、成员或部队变化后须重新选人和确认；禁止旧版接受悄悄扩大随迁家庭。
- 男女均可自立，被选择的本人为新族长，配偶随迁。族长本人及族长配偶不通过此事项迁走；成年子女、父母、兄弟姐妹不随迁。父母子女和婚姻引用保持不变。
- 新家族可保持独立或加入存续王国；入国沿用现有换国规则，无新增国王批准。新族以游戏模型的同伴受封起始等级建立，入国时至少达到当前封臣门槛，不复制原族声望/影响力。原版 `DefaultClanTierModel` 下起始为 2 级、150 声望，其他模组替换模型后以实际模型为准。
- 加入目标家族使用真实有效的普通贵族家族；归属由双方当前交涉确定，无第三方审批链。家族领袖、已灭族/叛军/匪徒/特殊佣兵家族不作为离族主体。
- 玩家家族即使尚无原版 IsNoble 标记也可接收/分家，不要求先入国；仍检查真实人物身份与家族领袖边界。
- 原版尚未出场的未成年子女可以随迁并保留儿童状态；未出场限制只针对成年决策者，不生成成年代理或强制让儿童出场。

## 旗帜与配色

- 自立调用 `Banner.CreateRandomClanBanner()`，不按姓名、人格、文化或原族旗帜计算，不做图案/颜色查重，也没有手动选旗入口。
- 初始 `Clan.Color` 取旗帜主背景色，`Clan.Color2` 取首个纹章颜色；入国后由原版 `UpdateBannerColorsAccordingToKingdom` 保留图案并改用王国主色和纹章色。加入已有家族不生成新旗帜，沿用目标家族的旗帜与配色。
- 已知限制：本轮只设置旗帜与 `Color/Color2`，未初始化原版用于退国恢复的 `BannerBackgroundColorPrimary/Secondary`、`BannerIconColor`。因此新族入国后再独立可能继续使用此前国家的颜色；此项尚未修复，不作为已完成行为描述。

## 资产与执行

- 个人金币、装备及本人率领的普通贵族部队保留；部队士兵、物资、俘虏不复制、不重建。资助完全属于双方报价，没有强制启动金或赠地。
- 人物 Clan 与部队 ActualClan 分别更新；跨阵营时脱离原军团，原模组任务撤销并交还原版 AI。总督任职解除。搭乘他人部队的离族者只离队，不能搬走别人的军队；本人部队中的非随迁英雄离队，原家族归属不变。
- 转族后身处敌对定居点的部队/无队成员按原版离开方式清理，保留原队伍；入国仍调用原版 ChangeKingdomAction，原版外交引起的贵族释俘等规则照常，不能承诺新盟友继续作为俘虏被拘押。
- 原族封地、族长金币、公共声望与影响力不迁移，不调用整个原家族换国。
- 被俘不阻止本人交涉、投族或自立，也不阻止家庭成员变更归属。俘虏身份、拘押对象、关押地点与俘虏名册不由迁移直接修改；不能对被俘成员套用普通驻留贵族的敌城离开/逃亡处理。另行约定的释放、原版入国释俘照常生效，不反向恢复拘押。
- 被俘者不读取关押地点的 SiegeEvent 来判断本人参战。非俘虏成员仍检查自己的部队战斗、部队围城和所在定居点被围状态；随迁家属阻止执行时明确标注「随迁成员」及实际姓名、原因。
- 战斗/围城、成年者未出场、逃亡、旅行等不稳定状态拒绝执行；丧偶孕妇须分娩后再处理，避免新生儿仍按已故父亲旧族归属。
- 不可用/正在解散的部队须先结束原流程；实际执行绑定的部队归属、领队及跨阵营军团变化均纳入检查，原生回调部分生效后不退款重试。
- 先清理原军团和任职，再注册新族并立即设置领袖，避免原军团回调失败留下无领袖的新族。
- 执行前绑定整个家庭和真实部队。与同族婚配/换国等组合条件共享资源冲突键。原生对象创建或任何成员/职务/部队变化已经发生时标记部分履行，不假称回滚，不自动重试。

## 客观记忆

- 成功记录走 handler.RecordApplied；原族长、接收族长和随迁 NPC 静默收到客观归属事实，不激活、不弹询问、不代写愤怒、感谢或复仇。关键成员变更直接用现有 AppendSystemDiary 的「情报」通道，避免被普通见闻日上限丢弃；不泄露私下谈判价码。
- 公共史料仅记实际迁移/建族与所属国家，交涉财物和未成交提议仍留在双方线程。
- 实时关系上下文只把同族称为家族成员，只有真实且非空的共同父母才标注同母/同父，避免投族者被误写成血亲。
- 不新增模组存档键、配置项、运行时依赖；建族与人物/部队归属由原生战役对象保存。读档与实机仍需验证。
