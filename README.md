# AI Chronicle · Words Become Deeds

**An "living world" mod for Mount & Blade II: Bannerlord** — LLM-driven NPC lords whose **words become reality**. When an AI lord says it will make peace, march its army, release you, or change allegiance, it actually *does* it in the game world — and every word is recorded by an AI historian into an in-game chronicle, becoming the shared memory of Calradia.

This is (to our knowledge) the only Bannerlord mod where what an AI *says* and what an AI *does* are unified. Because words become deeds, words become history.

## Concept

The mod is built on an **agent-driven architecture** inspired by agentic coding tools:

```
Entity (player & every NPC are the same abstraction)
      ↕
Context Builder (dynamically assembles identity + memory + goals + perception + available tools)
      ↕
Agent core (reads files, makes decisions, writes back, calls game functions)
      ↕
File system (each entity's own directory = structured memory)
```

Agents do not distinguish "player" from "NPC" — the player is just an Entity whose controller type is Human.

Key design principles:

| Principle | Description |
|---|---|
| **Entity equality** | Player and all NPCs are unified as `Entity`; `EntityController` (Human/Agent) distinguishes them |
| **Files as memory** | Each NPC has its own directory: `persona.txt`, `knowledge/`, `relationships/`, `goals/`, `decisions/diary.txt`, `chat_logs/` |
| **Information isolation** | Each NPC can only read/write its own files + the shared `World/` — no two NPCs share conversation context |
| **Everything is file-driven** | System prompts, tool definitions, persona generation rules, historian rules — all hot-reloadable files, no hardcoding |
| **Words become deeds** | `function calling` executes real game actions: march, raid, besiege, war, peace, alliance, trade, fief grants, prisoner release... |
| **History as shared memory** | A virtual "Historian" entity writes annual chronicles in the style of 《资治通鉴》, readable by every NPC |

## Features

### AI Lord Chat
- Talk to any lord through an in-game chat window with full conversation history.
- NPC personalities are generated by LLM on first contact (motivation / traits / speech style).
- While chatting, agents can use **50+ game tools** filtered by their actual capabilities (a landless commoner can't declare war; a king can).

### Persistent Correspondence
- **O** key: unified correspondence panel — every lord you've ever spoken to, unread badge counters.
- Writing a letter sends a *real* letter; delivery takes real game time based on distance. Replies arrive in the same thread.

### AI Diplomacy
- AI kings declare war, propose peace / alliance / trade, grant fiefs — the other king's agent reviews and responds.
- Proposals are stored in `World/diplomacy/` and processed asynchronously by the scheduler.
- Vanilla diplomacy can be fully replaced ("Ban Vanilla Diplomacy") so all diplomacy flows through the mod.

### Living History
- Major events (wars, peace, fief ownership, kingdom destruction/founding, noble deaths, marriages) are auto-recorded into raw sources (`World/history/events_{year}.txt`).
- At year's end the **Historian agent** (a virtual entity, no game NPC) writes an annual chronicle in classical-chronicle prose.
- **H** key: read the chronicle in-game. NPCs can also `read_file` the chronicles — history becomes shared knowledge.

### Internal Politics & Court
- **Fief review**: kings assign/reclaim fiefs; the deprived clan gets activated to react (protest, write letters, defect to another kingdom).
- **Advisories**: vassals submit public or secret advisories to their king (archived; public ones enter the chronicle).
- **Edicts**: kings publish edicts to the realm; vassals read them before advising.
- **Court merit records**: real battle contributions tracked for the king's internal review.

### Memory System
- **Diary-as-index**: each agent keeps `decisions/diary.txt` (`[year season day] type: content`) — timestamps link to full `chat_logs/`, so agents can recall decisions, promises, plans and their outcomes.
- **Memory consolidation**: before self-review activates, a consolidation pass appends new memorable events to the diary (guaranteed baseline, not reliant on agent self-discipline).

### Secretariate (M key)
- The player's personal administrative assistant — a fixed persona that always obeys.
- The player can execute diplomacy, submit advisories, publish edicts through it.

### Clan Replenishment ("Fate" system)
- A virtual entity `__fate__` activates when vassal/mercenary clan numbers drop below a threshold, creating new noble families with generated members.

### Intel Fog of War
- Troop queries give full detail for your own faction; hostile factions only get distance-based estimates (near / far / rumor), preventing "perfect information" stalemates.

## Requirements

- **Mount & Blade II: Bannerlord** (developed against **v1.4.7**)
- Four prerequisite mods (matching your game version):
  - Harmony (`Bannerlord.Harmony`)
  - ButterLib (`Bannerlord.ButterLib`)
  - UIExtenderEx (`Bannerlord.UIExtenderEx`)
  - MCM / MBOptionScreen (Mod Configuration Menu)

## Installation

1. Copy the `AIChronicle` folder into `...\Mount & Blade II Bannerlord\Modules\`.
2. Launch the game, enable **AI Chronicle: Words Become Deeds** and the four prerequisites in the launcher.
3. In the main menu: **Options → Mod Options → AI Chronicle** — fill in your API key (default endpoint: DeepSeek `https://api.deepseek.com/v1/chat/completions`, model `deepseek-v4-flash`), click **Test Connection**.
4. Start a new campaign. The mod creates a prompt directory per-campaign under `Prompts/Campaigns/`.

> The mod calls LLM APIs with **your** API key — API usage is billed to you. Choose a provider/model per your budget.

## Configuration

Each scenario (conversation / historian / diplomacy / correspondence / etc.) can have its own API URL / model / key in MCM, falling back field-by-field to the global "connection settings". A single "max tokens" setting controls all token budgets.

## Project Structure

```
AIChronicle/
├── SubModule.cs            # Mod entry point, lifecycle, Harmony registration
├── ToolExecutor.cs         # 50+ game tool implementations (query/military/diplomacy/economy)
├── AgentScheduler.cs       # Async event scheduler (letters/court/historian/advisories)
├── AgentManager.cs         # Agent file system, permissions, persona generation
├── ContextBuilder.cs       # Dynamic prompt assembly
├── AIChatClient.cs         # LLM streaming client (SSE, multi-round tool loop)
├── DiplomacyService.cs     # War/peace/alliance/trade/fief actions
├── PartyBehaviorManager.cs # Army behavior (march/raid/besiege/patrol/escort)
├── HistoryRecorder.cs      # Records raw history events
├── MemoryConsolidator.cs   # Diary consolidation
├── _Module/Prompts/        # All prompt files & tool definitions (hot-reloadable)
└── ... (see AGENTS.md for the full map)
```
