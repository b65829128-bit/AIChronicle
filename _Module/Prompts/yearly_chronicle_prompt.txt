请编纂卡拉迪亚第{year}年的编年史。

工作步骤：
1. 首先使用 read_file 读取 history/events_{year}.txt 中的原始史料，不传 line_count，尽量一次读全。若结果明确提示截断，再从最后完整显示的一行之后继续；末行若不完整，须重读该行，优先读完年度史料
2. 如需补充人物或定居点背景，使用 query_character 或 query_settlement 查询
3. 可选用 read_file 读取 curia/ 目录下的朝议记录、diplomacy/consults/ 目录下的国王外交问询作为补充视角（如某场战争/外交决策背后的各家族主张、投票与两国往来）——但原始史料始终是权威，朝议/问询仅供参考，引用时须注明"某次朝议中某家族的主张"/"两国国王当时的问询答复"而非史实；旧档 advisory/、edict/ 不再写入，只可作历史背景
4. 撰写年度编年史，使用 write_chronicle 工具落盘：体例=编年史，名称={year}，正文=编年史全文（系统自动存档为 {year}编年史.txt）

阅读与补查共用有限轮次，最后两轮只供 write_chronicle 成文和纠错。史料已足够时立即写年度正篇；背景查证与专题史均为可选，不要反复翻阅同一段而忘记落盘。

编年史格式要求：
- 篇名为「第{year}年编年史」（阅读页自动显示）；**正文不要重复写标题**
- 正文用 Markdown：`## 春` / `## 夏` / `## 秋` / `## 冬` 分节，每条事件独立成段
- 简洁白描，白话文书写，模仿《资治通鉴》风格
- 年末「史官曰」总评用 Markdown 引用块：`> 史官曰：……`
- 不要使用表格、图片、链接、HTML 标签或代码块；Markdown 只用于结构

- 即使该年事件极少，也应简要记录；没有史料的季节注明「事迹阙载」，不得仅凭缺载推断天下太平。未读全的史料不得假称已尽录

如果有灭国、大规模战役、王朝更替等重大事件，可以额外写专题史——使用 write_chronicle 工具落盘（体例=世家 记录一国兴衰，或 体例=纪事 记录事件始末，名称=国名或事件名）。
